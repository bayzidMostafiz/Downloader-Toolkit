Download installed themes, plugins, media files, and manage site files directly from your WordPress Dashboard.

== Description ==

Downloader Toolkit provides useful tools for managing and downloading WordPress files directly from the WordPress Dashboard.

With this plugin, you can:

* Download installed plugins
* Download installed themes
* Download media library files
* Browse and manage site files
* Edit files directly from the dashboard
* Upload files
* Delete files
* Manage WordPress site assets from one place

== Features ==

* Plugin Downloader
* Theme Downloader
* Media Downloader
* File Manager
* File Editor
* File Upload
* File Download
* File Delete

== Installation ==

1. Upload the `downloader-toolkit` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Open Downloader Toolkit from the WordPress Dashboard.

== Frequently Asked Questions ==

= Can I download installed plugins? =

Yes. Downloader Toolkit allows you to download installed plugins from your WordPress Dashboard.

= Can I download installed themes? =

Yes. You can download installed themes directly from the plugin.

= Can I manage site files? =

Yes. The plugin provides file management features such as editing, uploading, downloading, and deleting files.
